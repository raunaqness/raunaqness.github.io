# Automatic variants comparison

Source: carwale.com. Prices are CarWale's **Bangalore on-road prices** (ex-showroom + RTO/road tax, insurance, TCS and other charges). CarWale quotes them at city level only: it has no HSR Layout area option for Bangalore. Brochures are saved in `downloads/`. Only automatic gearboxes (CVT, DCT, torque converter) are included. Kia Sonet's clutchless-manual (iMT) variants are excluded.

**How to read each table:** the first row is the cheapest automatic and lists everything it has. Every later row lists *only what changes* compared with the variant named in **vs**: that is the previous variant with the same engine and gearbox, or the base variant when the engine/gearbox changes. So reading down a column shows what you get for each upgrade.
